# callosal-disconnection-eeg
MATLAB code for intraoperative EEG connectivity analysis during sequential corpus callosal disconnection.
# Callosal disconnection EEG analysis

MATLAB analysis code accompanying the manuscript:

**Sequential corpus callosal disconnection reveals preferential
interhemispheric network disruption**

## Repository status

This repository is being prepared for a versioned public release.
The analysis code, documentation and synthetic demonstration have not yet
been assembled and validated as a release package.

No archived software DOI has been assigned yet.

## Intended scope

The release is intended to document the manuscript's EEG preprocessing,
quality control, connectivity analyses and statistical modelling,
including:

- Primary interhemispheric wavelet transform coherence analyses.
- Exact-time-matched interhemispheric and intrahemispheric comparisons.
- Post hoc epoch-matched complementary analyses.
- Exploratory clinical analyses, with the data source for each
  connectivity-change measure documented explicitly.

The original and post hoc analysis paths will be distinguished.

## Data protection

Patient EEG recordings, MRI images, clinical spreadsheets,
patient-level derived datasets, saved clinical model objects and
patient identifier mappings must not be committed to this repository.

Local command histories, private configuration files, credentials and
unreviewed output files must also remain outside the repository.

Synthetic demonstration data will be generated without using patient
records. The demonstration will illustrate software operation and
will not reproduce or replace the clinical results reported in the
manuscript.

## Reproducibility

The release documentation will specify the MATLAB version, required
toolboxes, input formats, execution order and validation status.

Analysis code and demonstration files must be reviewed before the
repository is made public or a release is created.

## License and citation

The software license and citation metadata will be finalized before
public release. The manuscript will cite the archived DOI of the
specific software version used for submission.
