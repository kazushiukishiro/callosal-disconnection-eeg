公開完成版、32例の結果再現セット、v1.0.0ではありません。

1. ZIP全体を、研究フォルダーとは別の新しい場所へ展開してください。
2. MATLAB R2026aで展開フォルダーを現在のフォルダーにします。
3. 次を実行してください。
       demoOutDir = run_synthetic_demo();
       winopen(demoOutDir);
4. 結果フォルダーの SHARE_DEMO_REPORT.txt だけをChatGPTへ添付してください。

合成EDFを自動生成し、同じZIP内の原解析関数を使って処理します。
出力先は毎回新しいフォルダーです。研究フォルダーを検索せず、既存結果を上書きしません。

原解析ソース7ファイルは添付済みコードとバイト単位で同じです。
新しく作成したのは実行入口、合成記録の生成、設定、テスト処理です。
数式や臨床解析結果を合成データに合わせて変更したものではありません。

この環境にはMATLABがないため、新しい入口コードのMATLAB実行は未確認です。
途中で止まっても閾値変更やチェック削除はせず、レポートを添付してください。
